[![Coverage badge](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/dmitrysvd/wishes-backend/python-coverage-comment-action-data/endpoint.json)](https://htmlpreview.github.io/?https://github.com/dmitrysvd/wishes-backend/blob/python-coverage-comment-action-data/htmlcov/index.html)
